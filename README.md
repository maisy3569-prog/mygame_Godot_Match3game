#Match Three Puzzle Game

A match-three puzzle game developed using Godot 4 and GDScript.

#Overview

This project recreates the classic match-three gameplay mechanic where players swap adjacent tiles to form rows or columns of three or more matching pieces.

Matched tiles are cleared from the board, allowing new pieces to fall into empty spaces and create chain reactions.

#Features

-Tile swapping system

-Match detection algorithm

-Automatic tile clearing

-Gravity and tile dropping mechanics

-Board refilling system

-Combo and chain reactions


#Technologies Used

-Godot 4

-GDScript

#Objective

Match three or more identical pieces horizontally or vertically to score points and clear the board.
